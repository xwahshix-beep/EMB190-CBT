# 6.9.2-metrics

Wake-lock session accounting uses elapsedRealtime, caps each interval at the existing 90-second timeout, and includes screen-on time. It is not energy measurement. Scan cadence and timeout are unchanged. No Samsung battery measurement has been performed.

Long minute replay evaluated 10,042,830 bars on seven fixed symbols in 2022, 2025 and January–September 2026. Neither frozen variant met acceptance. Mean signal returns are not portfolio returns. These retrospective results do not evaluate the entire live pipeline. See long-validation protocol, code, manifest and summaries. The daily report is an explicitly labelled reproduction, not new independent validation.
